          Add your free Gemini key

          CodeLens answers questions with Google Gemini (model gemini-flash-lite-latest). Get a free key at aistudio.google.com/apikey and paste it here.

          The key stays in this browser (localStorage). It is sent with each question to this site's own proxy, which forwards it to Google and never stores or logs it. Your file's code is sent to Gemini only when you ask.

          How to read your city

          Every building is one file of your project

          • Height = lines of code. Taller buildings have more code.
          • Footprint = how much the file matters: bigger plots for files many others import.
          • Districts = folders. Files in the same folder share a block; small files are grouped into small blocks.
          • Colour: off by default; use Colour above the city to tint by module type or language (legend under the city).
          • The Vault = secret files (.env, keys). Only their names are known; contents are never read.
          • Roads and arcs = imports. Select a building: orange arcs go to files it uses, blue arcs come from files that use it.
          • Click a building to talk to it, double-click to open its code.
          • Scroll (or pinch) to zoom, right-drag or Shift+drag to pan, left-drag to rotate.
